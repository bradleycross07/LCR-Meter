# enclosure

Enclosure designs for the LCR meter, made in Fusion 360.

The enclosure is a two-part ABS case with an overlapping lid, cut-outs for the
16×2 LCD and the two buttons, and a terminal block for the component under
test. It is assembled with four steel screws.

## What goes here

| Format          | Why                                                   |
| --------------- | ----------------------------------------------------- |
| `.f3d`          | Fusion 360 archive (the editable source)              |
| `.step`         | Neutral CAD format, opens in other tools              |
| `.stl`          | For 3D printing                                       |
| `.png` / `.mp4` | Renders and animations for reports                    |

Name files with a version number, e.g. `enclosure-v2.f3d`, and note what
changed in the commit message.
